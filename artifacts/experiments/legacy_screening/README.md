# 📦 Arsip Skrining Model Awal (`artifacts/experiments/legacy_screening/`)

Direktori ini memuat artefak eksperimen historis tahap skrining awal (*candidate models screening*) sebelum pelaksanaan validasi terpadu resmi (`decisive_validation/rev05/`).

---

## 📑 Berkas Arsip

| Berkas | Format | Keterangan |
| :--- | :---: | :--- |
| `candidate_models_screening_leaderboard.csv` | CSV | Papan peringkat perbandingan model kandidat pada evaluasi awal. |
| `baseline_7b_predictions.csv` | CSV | Prediksi inferensi model baseline 7B pada evaluasi skrining awal. |
| `baseline_7b_metrics.json` | JSON | Ringkasan metrik akurasi dan kesenjangan bahasa tahap skrining awal. |
| `decisive_validation_raw_results.csv` | CSV | Hasil mentah eksperimen awal sebelum pembekuan rev05. |
| `decisive_validation_manifest.csv` | CSV | Manifest data pasangan awal yang digunakan pada fase skrining. |
| `bilingual_pair_manifest.csv` | CSV | Manifest pasangan bilingual awal. |
| `factorial_2x3_final_summary.csv` | CSV | Ringkasan eksperimen faktorial $2 \times 3$ awal. |
| `factorial_2x3_interaction_plot.png` | PNG | Plot interaksi faktorial awal. |
| `risk_coverage_curve.png` | PNG | Kurva risk-coverage eksplorasi awal. |

---

> [!NOTE]
> Seluruh metrik, evaluasi, dan klaim ilmiah resmi skripsi mengacu secara eksklusif pada:  
> [`artifacts/experiments/decisive_validation/rev05/`](../decisive_validation/rev05/).

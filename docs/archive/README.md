# 📦 Historical Documentation Archive (`docs/archive/`)

Direktori ini berfungsi sebagai tempat penyimpanan draf naskah penelitian versi terdahulu (v9 dan v10).

---

## 🔒 Tujuan Pengarsipan
Arsip ini dipertahankan secara non-destruktif untuk:
1. **Integritas Audit Historis:** Membuktikan alur berpikir dan evolusi metodologi riset secara transparan kepada dosen penguji atau reviewer jurnal.
2. **Kepatuhan Anti-HARKing:** Menunjukkan rumusan hipotesis awal sebelum eksperimen rev05 dijalankan dan sebelum metode Bi-ViS diformalkan.
3. **Mencegah Kerusakan Tautan Historis:** Menjamin log perubahan sebelumnya tetap memiliki rujukan naskah asal.
